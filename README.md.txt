# Basic Student Profile — Mobile App

A basic student profile app built for ITCC 41 (Mobile Application Development), using HTML, CSS, and JavaScript, packaged as an Android app with Cordova.

## Features
- Header with profile picture, name, and "About Myself" subtitle
- Navigation menu that switches between About and Skills sections
- About section covering interests, education, and goals
- Skills section with 5+ skills and animated progress bars
- Footer with copyright, name, and current year
